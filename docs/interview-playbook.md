# Mental Execution Flow

1. Understand requirement (fast) — ask clarifying questions if needed
2. Define simple Prisma schema
3. Build backend service first
4. Add controller + route
5. Add validation (Zod)
6. Build frontend hook
7. Build UI component
8. Test full end-to-end flow

---

## 🏆 Golden Rule

Always build a vertical slice first (end-to-end working feature).
Do NOT build backend/frontend separately.

---

## 🧯 If Stuck

Simplify → isolate → get working version → refine later
